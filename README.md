# Horror Game

A 3D first-person psychological horror game built in Unity.

## Overview
Navigate through dark, tense environments, manage power with the generator system, solve puzzles, and survive against hostile entities.

## Features
- **Atmospheric Exploration**: Navigate dark corridors with an interactive flashlight and dynamic lighting.
- **Power Management**: Fuel the generator to keep building power and essential lights running.
- **Enemy AI**: NavMesh-driven enemies with chase and jumpscare mechanics.
- **Puzzles & Progression**: Collect keys, unlock doors, decipher notes, and assemble items to advance.
- **Save System**: Checkpoint and game progress saving.

## Controls
- **Movement**: WASD
- **Look**: Mouse
- **Interact / Pick Up**: E
- **Flashlight**: F
- **Run**: Left Shift
- **Crouch**: Left Ctrl / C
- **Pause Menu**: Esc
